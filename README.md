# Random Password Generator (Генератор случайных паролей)

## Автор
**Богдан Стыценко**

## Описание
Random Password Generator - это графическое приложение на Python для генерации безопасных случайных паролей. Приложение позволяет настраивать длину пароля и типы используемых символов, сохраняет историю сгенерированных паролей в JSON-файл и поддерживает копирование паролей в буфер обмена.

## Функциональные возможности

### Основные функции
- **Генерация паролей** с настраиваемыми параметрами
- **Настройка длины** пароля от 4 до 32 символов (с помощью ползунка)
- **Выбор типов символов**:
  - Цифры (0-9)
  - Буквы (A-Z, a-z)
  - Специальные символы (!@#$%^&*()_+-=[]{}|;:,.<>?)
- **Копирование пароля** в буфер обмена одним кликом
- **История паролей** с сохранением даты и времени генерации
- **Сохранение и загрузка** истории в/из JSON-файла
- **Очистка истории** с подтверждением

### Проверки валидности
- Минимальная длина пароля: 4 символа
- Максимальная длина пароля: 32 символа
- Обязательный выбор хотя бы одного типа символов

## Требования к системе
- Python 3.6 или выше
- Стандартные библиотеки Python (tkinter, random, string, json, datetime, os)
